# 实时短信独立采集与本地可见性

## 范围与接收路径

保留厂商短信为默认应用。实时采集直接解析受 BROADCAST_SMS 保护的 SMS_RECEIVED PDU，
不查询短信库、不等待 SIM 刷新或网络；先保存至 captures/outbox，再由 WorkManager 同步。
READ_SMS 历史补扫失败不影响实时链路。长短信合并、广播指纹及跨接口去重规则保持不变。
历史/SIM 维护使用独立、无网络约束的 WorkManager 任务；中枢同步不等待 provider 或 SIM 服务，
维护提交后再唤醒上传。历史 provider 卡住不能占据上传任务或身份锁。
旧历史/legacy 队列的显式单卡兜底在维护任务中验证并事务填充空号码；新广播的未知订阅不启用此兜底。
上传只读取已确认快照或精确订阅映射，不再调用 SIM 服务来验证兜底，避免 SIM 服务阻塞实时上传。

总开关关闭停止两种采集，但不删除队列。历史补齐独立开关：已有 upload 用户继承原行为，
新用户默认不开历史；权限按功能分别申请。开启开关并不表示系统已授予权限或验证广播可达。
关闭总开关也停止后续上传批次；已经发出的 HTTP 请求不能撤回，仍处理其确认以避免重复队列。

## 并发与身份

开关关闭/重新开启、连接身份切换递增 capture_generation。广播入口快照代次，短事务保存前复核；
旧代次事件不写入新身份。历史扫描在身份锁外访问 provider，仅每批提交时锁定并复核代次。
广播保存使用已确认的精确订阅号码快照，缺失订阅不按当前卡槽推测；后台更新映射不重写旧快照。

## 本地展示与隐私

设置中的“本机待同步短信”分页展示全部 outbox，包括尚未映射与异常记录，离线可查看。
状态区分等待号码确认、记录异常、中枢禁止上传、采集关闭及待上传；可跳转已有 SIM 配置。
ACK 后才删除待同步行；普通收件箱继续展示中枢已同步记录，避免混用临时 ID 或错误合并。
页面包含正文，必须由用户主动打开；系统通知和诊断不包含正文。无编辑、猜测归属或删除队列入口。

实时诊断在 SQLite meta 持久计数、最近广播时间和最近成功保存时间，失败仅使用固定类别。
历史状态采用枚举，不以“短信读取正常”字符串前缀推断实时健康。

## 升级与回退

SQLite v5→v6 只 INSERT OR IGNORE 新 meta 键及增加队列时间索引，无破坏性转换；保留队列、去重账本、SIM、历史水位与身份。
v3/v4 的既有迁移照常执行。SharedPreferences 新开关懒迁移时继承旧 upload 意图，不能因先关闭总开关而丢失意图。
旧 APK 不支持直接打开 v6 数据库；不得卸载/清库回退。保留升级前的受控本地备份，或发布兼容 v6 的修复 APK；
不在本任务自动安装、创建备份或更改生产数据。服务端 schema/API 与版本号不变。

## 验收边界

自动化覆盖分离权限、历史 provider 阻塞/异常、重复广播、长短信、未知 SIM、代次竞态、离线持久化、ACK 与迁移。
合同放在 Android `src/sharedTest`，宿主测试使用 API 35 + Robolectric native SQLite，设备测试复用同一合同。
合成 PDU 验证解析与拼接；SQLite reopen 验证落库持久性，而非断电、真实手机重启或系统广播投递证明。
真机必须保持厂商短信默认，测试普通新 SMS、长短信、双卡、断网、重启解锁及恢复网络。
对照 SmsForwarder 时核实日志来源是 sms 而不是 app 通知。
关机、强制停止、厂商屏蔽广播、首次解锁前 Direct Boot 不属于本轮保证，不承诺绝对即时或不漏收。
不新增通知监听、默认短信角色、私有 URI、验证码保护绕过或厂商历史导入。

### 澎湃真机检查表（均需实测，不以编译替代）

1. 记录机型、Android/澎湃版本、鸿枢版本与双卡配置，确认厂商短信仍为默认应用。
2. 开启实时、关闭历史或撤销 READ_SMS；用另一台设备发普通新 SMS，检查本地页正文、时间及实时计数。
3. 打开历史补齐并复现历史不可读；再发新 SMS，确保本地页新增且中枢仍可同步。
4. 分别给两张卡发不同合成正文，再发长短信；确认号码准确、拼接完整，每条仅上传一次。
5. 断网收新 SMS；重启并首次解锁后查看本地页，恢复网络，确认 ACK 后待传消失且中枢记录可见。
6. 不确认 SIM 的情况下接收；记录必须保留并显示待确认，不应被按卡槽或新换的 SIM 猜测上传。
7. 关闭后发 SMS 不采集，再开启收新 SMS；系统强制停止后必须先重新打开应用再测试。

测试使用合成内容，不在 issue、日志或诊断导出真实号码、正文或验证码。
