# 鸿枢 v0.1.0-alpha.8

本版本重构了 Android 客户端用户界面，全面对齐 Google Messages（谷歌短信应用）视觉交互与 Material 3 规范，支持深色模式并移除了截屏限制。本版本是 GitHub **Pre-release**，仍属 alpha，不是稳定版。

## 新增与调整

- **移除截图限制**：移除了 Android 端 `FLAG_SECURE` 窗口标志，允许正常截屏与屏幕录屏。
- **深色模式与动态取色**：支持 Google Messages 同款 AMOLED 纯黑/深灰质感，适配系统深浅模式切换，在 Android 12+ 设备上支持 Material You / Monet 动态取色。
- **Google Messages 首页布局**：
  - 顶栏采用沉浸式标题排版，集成搜索功能与标志性圆形用户头像；
  - 列表项采用平整流式布局，提供大号正圆形彩色头像（马卡龙多色自适应）、智能紧凑时间格式与最新内容预览；
  - 右下角提供 Extended FAB“开始聊天”与双向云同步辅助悬浮按钮。
- **Google 风格账号与设置面板**：点击右上角头像展开卡片式账号面板，分层收纳中枢连接凭据、SIM 识别配置、实时推送链路与历史短信导入。
- **对话详情气泡**：重构会话历史消息为非对称圆角气泡与时间标注。

## 升级与回滚

中枢部署基于发布镜像标签（如 `0.1.0-alpha.8`）。升级时拉取新镜像并重启：
```bash
docker compose pull hub
docker compose up -d hub
```

本版本未修改数据库 Schema 与接口契约，可随时平滑回滚至 `v0.1.0-alpha.7`。

## 验证边界

发布工作流已运行真实隔离 MySQL 上的 Go race/vet 集成测试、浏览器 smoke 测试、Android 单元测试/lint 以及 Release 签名验证。
