# 鸿枢 v0.1.0-alpha.19

本版本修复 Android 客户端“实时广播与同步”页面点击任意按钮后整页变灰、无法操作、必须重启应用的问题。版本仍属 alpha，为预发布版本，不是稳定版。

## 本次更新

- **修复设置页点击后卡死**：设置页是全屏独立页面，没有显示主页提示条的位置，而旧逻辑要等提示条显示并消失后才解除“忙碌”状态，因此提示永远不会结束，整页一直禁用。现在无论操作成功、失败还是被取消，都会立即解除忙碌状态，提示与此互不等待。
- **设置页不再向主页排队提示**：设置页本来就在页面内显示操作结果，不再向看不见的主页提示条重复排队，避免返回首页后连续弹出过期提示。
- **取消不再误报为失败**：被取消的操作不再显示成“操作失败”。
- 新增 4 项单元测试，覆盖“没有提示条时仍会解除忙碌”“失败信息仍会提示”“取消后解除忙碌”。

## 升级与回滚

Android 本地数据库与设置不变，直接覆盖安装即可；服务端 API 与 schema 无变化，镜像按版本标签发布（如 `0.1.0-alpha.19`）。中枢无需为本次修复升级，如需同步版本：

```bash
docker compose pull hub
docker compose up -d hub
curl --fail http://127.0.0.1:18473/healthz
```

如需回滚中枢，在 `.env` 中使用上一版本镜像标签 `0.1.0-alpha.18` 并重新执行上述步骤。Android 不支持直接降级安装，卸载会清除本地待同步队列，不建议回退 APK。

## 验证边界

CI 已运行 Android JVM 单测（含新增的操作状态测试）、lint、APK 构建，以及 API 28/33/35 模拟器设备测试、Go/MySQL 与 Web 测试。尚未在目标真机上确认页面不再卡灰；澎湃 OS 上的厂商授权读取、系统设置跳转与短信通知兜底仍需按 [HYPEROS_SMS.md](https://github.com/IGNGserver/hongshu/blob/main/docs/HYPEROS_SMS.md) 的矩阵验收。
