# 鸿枢 v0.2.0-alpha.21

本版本为 alpha 预览版。

## 本次更新

- Android 客户端从 GitHub 仓库的静态更新清单直接检查并下载应用版本，不再通过鸿枢中枢转发更新请求。
- 用户可自行选择稳定版或预览版通道；预览版可接收预发布和更高的正式版本，稳定版只接收正式版本。
- 检查结果使用缓存和退避，减少重复请求；切换通道、检查或下载都不会安装低于当前版本的版本。
- 下载前复核版本、安装包身份与签名，避免清单变更或错误资产被安装。

## 快捷下载

- [直接下载 Android APK](https://github.com/IGNGserver/hongshu/releases/download/v0.2.0-alpha.21/Hongshu-Android-0.2.0-alpha.21.apk)
- [下载部署文件包](https://github.com/IGNGserver/hongshu/releases/download/v0.2.0-alpha.21/hongshu-v0.2.0-alpha.21-deployment.tar.gz)
- 中枢镜像：`ghcr.io/igngserver/hongshu:0.2.0-alpha.21`

## 升级说明

升级中枢前请备份数据库和 `.env`。应用内更新只允许升级；若需回退服务端，请依据数据库兼容性、备份与部署流程单独处理，不要清除数据库卷。

## 验证

- PR CI 对服务端、Web 和 Android API 28/33/35 执行验证；发布工作流会在 tag 后重新运行验证并构建、检查签名 APK、部署归档与中枢镜像。
- 真机签名安装、覆盖升级和不同厂商后台策略仍需目标设备验收。

## 已知限制

- 本版本仍为 alpha 预览版，不是稳定版；CI/模拟器结果不能代替真机安装验收。
