# 鸿枢 v0.2.0-alpha.18

本版本在 v0.2.0-alpha.17 基础上，为 Android 客户端实现平板与横屏自适应前端设计，包含 Material 3 Expressive 双栏主页、短对话顶部自然流式对齐、设置页主从双栏导航、横竖屏旋转状态保持及三级返回栈优化。仍为 alpha 预览版，不是稳定版。

## 本次更新

- **统一自适应断点规范**：抽象 `AdaptiveLayoutSpec`，无缝支持手机竖屏（单栏）、手机紧凑横屏（双栏紧凑）、小平板/折叠屏与大尺寸平板横屏（双栏宽展），在不同屏幕尺寸下自适应调整列表分栏宽度、卡片外边距与最大阅读列宽。
- **主页与会话详情双栏精修**：主页采用左侧列表与右侧 `28.dp` 白色大圆角详情卡片；双栏模式下短对话采用顶部自然流式对齐（`Alignment.Top`），消除卡片上半部分的视觉空白；气泡最大列宽放宽至 `460.dp`；在横屏垂直空间紧凑（`height < 480dp`）时自动隐藏冗余大引导卡并收紧间距，保证首屏短信完整可见。
- **设置页双栏主从分栏**：横屏与平板下，设置页自动切换为左侧总览导航（带选中高亮胶囊）与右侧子页面详情卡片，并通过 `LocalSettingsPaneStyle` 自动隐藏二级页面的重复返回箭头并切换紧凑标题栏，覆盖全部 7 个设置子页面。
- **横竖屏操作与逻辑一致性**：引入 `AppDestinationSaver` 支持跨屏幕旋转持久化当前对话与设置子页状态；优化返回栈逻辑，横屏双栏下退出对话详情不丢失列表状态，子设置项返回总览，返回操作与竖屏直觉严格同构。
- **兼容性**：仅优化 Android 客户端界面与布局状态，无服务端 API、数据库 schema、同步协议或 Web 客户端变更；升级无需迁移，已有短信、已读状态与设置保持不变。

## 升级与回滚

升级中枢前先备份数据库和 `.env`，把部署目录的 `HONGSHU_VERSION` 设为 `0.2.0-alpha.18`，然后运行：

```bash
docker compose pull hub
docker compose up -d hub
curl --fail http://127.0.0.1:18473/healthz
```

本版本不改数据库 schema；若健康检查失败，把 `HONGSHU_VERSION` 改回 `0.2.0-alpha.17` 并重启 hub，不要删除数据卷。数据库、备份和既有设备授权不受影响。
