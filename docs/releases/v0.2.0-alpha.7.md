# 鸿枢 v0.2.0-alpha.7

本版本是完成系统深度审计与可靠性整改的 alpha 预览版，不是稳定版。升级前请备份数据库和部署 `.env`。

## 本次更新

- **并发与身份隔离**：
  - 修复 Android 登录响应、SQLite 重置与 SharedPreferences 的跨边界原子性，增加持久 `identity_changing` 栅栏；
  - 修复离线上传开关切换与快速重复切换时的版本确认；
  - 修复 OTP 通知 tag 与 PendingIntent 身份代次折叠，避免同 ID 覆盖与敏感验证码剪贴板预览。
- **跨设备已读与订阅安全**：
  - 新增 `GET /api/read-state` 共享会话已读分页下行，按 epoch、已读修订和消息头保证快照一致性，不把下行合并当作新回执重新上报；
  - 会话标读输入严格限制在当前发件人现存消息，拒绝非法与未来消息 ID；
  - 消除 WebSocket 高频全库聚合，改用单调已读变更标记；
  - 包含显式执行的 `scripts/repair-read-watermarks.sql` 修复存量异常会话水位，不随启动自动运行；
  - Push 订阅在事务内重新锁定并复核设备撤销状态，修复已认证请求在退出登录后复活订阅的竞态。
- **通知捕获与去重可靠性**：
  - 通知同源区分重放与连续独立短信，不再使用滑动时间窗口把同发件人/同正文短信误合并；
  - 引入持久上传指纹账本，不同通知身份映射到同一上传指纹时，保留后续观察为明确的待处理碰撞项，不再被服务端 duplicate ACK 静默删除；
  - 即时关联与历史关联统一来源缺槽判定，已 ACK 的另一来源记录继续参与候选竞争；
  - Android SQLite 升级至 version 10，保留旧账本并标注身份歧义。
- **AI 队列并发优化**：
  - AI 候选扫描移出全局设置锁，改用快照排序并在短事务内原子复核与记账；
  - 修复持续上传期间由于全局修订变化导致 AI 任务无法领取的饥饿问题。
- **Web / PWA 与构建发布安全**：
  - 恢复 Web 端管理员撤销设备与浏览器身份的入口；
  - 修复会话尾页验证与后台切前台时的已读标记者；
  - 发布工作流强制校验 checkout commit 与输入 tag SHA 一致，并验证部署归档包含修复脚本。

## 升级与回滚

升级前做好数据库和 `.env` 备份，将 `.env` 中的 `HONGSHU_VERSION` 改为 `0.2.0-alpha.7`，执行 `docker compose pull hub` 和 `docker compose up -d hub`，再检查 `/healthz`、`schema_migrations` 和客户端同步状态。中枢数据库无需新增迁移表。若存量会话已读水位存在历史异常，可在所有实例升级后按部署文档执行 `scripts/repair-read-watermarks.sql`。

如需回滚，可将 `HONGSHU_VERSION` 改回 `0.2.0-alpha.6` 并重新启动容器。
