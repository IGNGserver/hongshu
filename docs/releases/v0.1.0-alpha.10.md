# 鸿枢 v0.1.0-alpha.10

本版本重构了中枢 Origin 与请求 Host 校验机制，与观澜（guanlan）、计然（jiran）中枢配置对齐，支持回环地址 `127.0.0.1` 默认配置和局域网多设备自适应访问。本版本是 GitHub **Pre-release**，仍属 alpha，不是稳定版。

## 新增与调整

- **中枢 Origin 校验重构**：
  - 动态匹配请求 Host 与反向代理 `X-Forwarded-Host`，消除因中枢配置 `127.0.0.1` 而局域网 IP 访问报错 `403 origin_denied` 的问题；
  - 对持有 Bearer Token 凭证的 Native 客户端请求豁免 Origin 头检查；
  - 保持针对恶意来源 Origin 的 CSRF 防护。
- **Android 客户端网络请求优化**：
  - 携带 Bearer Token 的 API 请求不再强制覆盖发送服务端全等 Origin 头。
- **Compose 与部署配置对齐**：
  - `compose.yml` 中 `PUBLIC_URL` 回退到默认 `http://127.0.0.1:18473`，移除启动强校验阻断；
  - `.env.example` 与 `init-deployment.sh` 默认使用 `http://127.0.0.1:18473`。

## 升级与回滚

中枢部署基于发布镜像标签（如 `0.1.0-alpha.10`）。升级时拉取新镜像并重启：
```bash
docker compose pull hub
docker compose up -d hub
```

本版本向后兼容既有配置与数据库结构，无需数据库迁移。

## 验证边界

发布工作流已运行真实隔离 MySQL 上的 Go race/vet 集成测试、浏览器 smoke 测试、Android 单元测试/lint 以及 Release 签名验证。
