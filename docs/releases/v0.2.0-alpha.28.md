# 鸿枢 0.2.0-alpha.28

本版本为 alpha 预览版，Android 通话页与短信页共用同一套搜索与筛选骨架，切换标签不再整页硬切。无数据库 schema 迁移，可从 `0.2.0-alpha.27` 平滑升级。

## 本次更新

- **通话页与短信页同一套页头**：通话页不再只有标题行，顶部复用短信页的搜索胶囊、`短信 / 通话` 分段按钮、线路筛选和类型筛选轨；切换标签只替换筛选轨与列表内容，搜索、设置入口和页面骨架保持不动。
- **通话搜索**：搜索号码子串、中枢别名和本机通讯录姓名，沿用 250ms 防抖；搜索中切换标签会保留关键词，换一个数据域继续搜索。双栏下从搜索结果的通话详情返回时，左栏仍停留在搜索结果。
- **通话类型筛选与计数**：提供“全部通话 / 未接 / 呼入 / 呼出 / 语音信箱”，计数与列表共用同一套筛选语义（未接含拒接、拦截；呼入含其他设备已接听；厂商未知类型只计入全部）。线路筛选按标签页各自记忆，未知线路只在“全部通话”中出现。
- **切换与列表动效**：筛选轨做方向性滑入淡出，列表交叉淡化，线路行高度展开/收起；通话行和日期头补上出现/位移动画；两页各自保留滚动位置，筛选或搜索变化才回到顶部。
- **通话页状态补齐**：首帧加载从空白改为居中指示器；补齐搜索无结果、筛选为空、无数据三种空态；下拉刷新统一为 Expressive 指示器；通话行线路标签统一为“卡1 · 8000”并移到时间旁边，窄栏不再截断通话摘要。
- **导航细节**：搜索中切换标签保留搜索态；通话页隐藏“全部已读”，齿轮沿用注意力角标；双栏通话详情与搜索左栏可以同时存在。

## 已知边界

- Web/PWA 通话页暂未加入搜索和类型筛选：Web 没有本地全量通话缓存，需要服务端 `/calls` 支持查询参数，本次只落 Android。
- 通话页布局已用 Robolectric 渲染手机、深色和平板双栏核对；滑动、弹簧与低端机/系统“移除动画”下的手感仍建议真机抽测。
- 未新增数据库迁移；alpha.27 的拔卡残留清理、alpha.26 的 iOS PWA 与小米/澎湃通知样式等边界仍适用。

## 升级与回滚

中枢无需新增数据库迁移：在部署 `.env` 中将 `HONGSHU_VERSION` 更新为 `0.2.0-alpha.28`，执行 `docker compose pull hub && docker compose up -d hub` 即可升级。如需回滚，把 `.env` 中的 `HONGSHU_VERSION` 改回原版本（如 `0.2.0-alpha.27`）并重新执行 `docker compose up -d hub`。Android 直接覆盖安装同签名 APK，不清除已有数据。
