# 鸿枢 v0.2.0-alpha.20

本版本为 alpha 预览版。

## 本次更新

- Android 客户端直接从 GitHub 仓库更新索引检查和下载应用版本，不依赖鸿枢中枢转发更新请求。
- 用户可以自行选择稳定版或预览版通道；切换通道只会在存在更高版本时更新，不会降级。
- 更新检查使用缓存和退避，避免频繁重复访问仓库；下载前会校验选定通道与目标版本。

## 快捷下载

- [直接下载 Android APK](https://github.com/IGNGserver/hongshu/releases/download/v0.2.0-alpha.20/Hongshu-Android-0.2.0-alpha.20.apk)
- [下载部署文件包](https://github.com/IGNGserver/hongshu/releases/download/v0.2.0-alpha.20/hongshu-v0.2.0-alpha.20-deployment.tar.gz)
- 中枢镜像：`ghcr.io/igngserver/hongshu:0.2.0-alpha.20`

## 升级说明

这是预览版更新。升级中枢前请备份数据库和 `.env`；应用内更新不会执行降级。若部署需回退，请按现有备份与部署流程处理数据和服务版本。

## 验证

- 更新功能分支的仓库校验、服务端、Web 和 Android API 28/33/35 CI 已通过。
- tag 发布工作流会再次运行服务端与客户端验证，构建并校验正式签名 APK、部署归档和中枢镜像；发布结果以该工作流为准。

## 已知限制

- 本版本仍是 alpha 预览版，不是稳定版；真机签名安装和升级结果以 GitHub Release 资产发布后的验收为准。
