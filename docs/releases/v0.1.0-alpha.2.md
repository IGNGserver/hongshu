# 鸿枢 v0.1.0-alpha.2

首版开发修复与加固预览版。必须在 GitHub 上显示为 **Pre-release**。

## 改进与修复内容

- **Android 待传队列熔断**：单条超过大小预算（> 900KB）或异常消息自动隔离标记为 invalid_message，移除硬中断，防止阻塞整个待传队列与 WorkManager 重试。
- **联系人批量同步**：服务端 `/api/contacts` 支持批量结构 `{contacts: [{phone, name}]}`（单批最多 500 条）在单个事务内原子更新；Android 端改为每 500 条分批上报，消除千级联系人时的网络风暴。
- **Android 实时服务生命周期修复**：WebSocket 断开后二次确认凭据与通知设置，身份失效或被撤销时立即退出协程，杜绝退避重试死循环。
- **SIM 候选展示健壮性**：针对 `slot = -1`（未识别卡槽或 eSIM）场景展示为“卡槽未知”，输入框置空供手动填写，避免展示为卡槽 0 导致误解。
- **服务端 WebSocket 内存广播**：引入内存 Pub/Sub 事件通道，新短信提交后毫秒级唤醒长连接，废弃每个客户端每 2 秒查询 MySQL `sync_clock` 的高频空轮询机制。
- **Web 端搜索防竞态**：为会话列表刷新与详情历史加载引入 `AbortController` 信号控制，快速切换或搜索时自动取消旧请求，防止乱序覆盖最新界面。
