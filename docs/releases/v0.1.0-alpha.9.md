# 鸿枢 v0.1.0-alpha.9

本版本优化了 Android 客户端的顶部边距排版与标题名称，接入系统级沉浸式边缘到边缘（Edge-to-Edge），修复双重状态栏内边距导致的过大留白问题。本版本是 GitHub **Pre-release**，仍属 alpha，不是稳定版。

## 新增与调整

- **标题更正**：将首页硬编码的“Google 信息”更正为标准本地化应用标题“信息”。
- **沉浸式 Edge-to-Edge**：
  - Activity 接入 `enableEdgeToEdge()`；
  - 清除 `Scaffold` 与系统状态栏的多重叠加内边距，透明化系统状态栏与导航栏底色，消除顶部过大留白。

## 升级与回滚

中枢部署基于发布镜像标签（如 `0.1.0-alpha.9`）。升级时拉取新镜像并重启：
```bash
docker compose pull hub
docker compose up -d hub
```

本版本仅优化 Android 客户端界面与内边距，未修改接口契约与数据库。

## 验证边界

发布工作流已运行真实隔离 MySQL 上的 Go race/vet 集成测试、浏览器 smoke 测试、Android 单元测试/lint 以及 Release 签名验证。
