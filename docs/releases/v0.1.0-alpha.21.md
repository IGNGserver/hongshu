# 鸿枢 v0.1.0-alpha.21

本版本修复 Android 客户端连接中枢时密码输入框使用普通键盘的问题，改为请求系统密码键盘。版本仍属 alpha，为预发布版本，不是稳定版。

## 本次更新

- **使用密码键盘输入中枢密码**：Android 设置页的“中枢密码”输入框现在声明密码输入类型，系统会使用密码键盘并继续遮罩密码内容。
- **不改变认证行为**：密码仍按原样提交，已连接中枢时留空密码保存设备名称的行为不变；服务端 API、数据库 schema 和本地数据无需迁移。

## 升级与回滚

Android 数据库无需迁移，可直接覆盖安装；中枢服务端 API 与数据库 schema 无变化。升级中枢时使用版本镜像并检查健康状态：

```bash
docker compose pull hub
docker compose up -d hub
curl --fail http://127.0.0.1:18473/healthz
```

如需回滚中枢，在 `.env` 中将镜像版本改回 `0.1.0-alpha.20`，再执行上述命令。Android 不支持直接降级安装；卸载会清除本地待同步队列，不建议通过卸载回滚 APK。

## 验证边界

发布工作流会重新执行仓库合同检查、真实 MySQL 集成、Go race/vet/build、Web 测试与构建、浏览器冒烟、Android 单测/lint/签名 APK 构建及 API 28/33/35 模拟器测试。本版本未在目标真机上确认不同厂商密码键盘的具体布局；系统键盘是否提供密码专用布局仍由用户设备的输入法决定。
