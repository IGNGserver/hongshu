# 鸿枢 v0.1.0-alpha.1

首个可部署开发预览版。必须在 GitHub 上显示为 **Pre-release**；此 alpha 不代表稳定、生产就绪或 Android 厂商兼容性认证。

## 内容

- Android 短信采集、SIM 映射、历史导入、离线 outbox 和独立上传/通知控制。
- Go/MySQL 中枢：一次性配对、设备撤销、幂等事务上传、持久历史、顺序游标、WebSocket 与 Web Push。
- Web/PWA 收件箱、历史搜索、设备/SIM 筛选与管理；浏览器不持久缓存短信正文。
- Docker Compose、本地 MySQL 数据卷、迁移校验、每日逻辑备份和恢复文档。

## 验证

- Go 1.26.4 + MySQL 8.0.36：race 测试 11 项通过（含 5 个真实数据库集成测试及隔离 dump/restore），vet 和主服务/VAPID/healthcheck 构建通过。
- Node 22：Web 6 项测试、语法和生产构建通过；Chromium smoke 覆盖初始化、实时连接与增量更新、XSS、手机布局、搜索、设备/设置及 PWA 私有缓存。
- JDK 17 / Android SDK 35：Android JVM 测试 5 项、lint、debug APK 和 androidTest APK 构建通过。Lint 有 33 条警告、无错误；androidTest APK 未在设备/模拟器执行。
- GitHub Actions：Go/MySQL 8.4.5、Web、仓库校验和 Android 全部通过；见 [验证运行](https://github.com/IGNGserver/hongshu/actions/runs/37908227348)。
- CI 发布工作流会在 tag 时再次执行完整验证，并只在成功后创建带校验和的预发布资产。

## 资产与安装边界

Release 自动附带 Linux amd64 中枢工具、Web 资源归档、OCI 镜像归档、Android debug APK 和 `SHA256SUMS`。使用前先校验：

```bash
sha256sum -c SHA256SUMS
```

Android APK 使用 debug 签名，仅供试用；不是 Play 商店包，也不能作为生产签名/升级通道。正式自签名构建见 `android/README.md`。OCI 归档可用 `docker load` 导入；部署前仍需按 `docs/DEPLOYMENT.md` 准备 HTTPS、受保护 `.env`、本地 Linux 数据盘及备份。

## 已知限制

- 本次没有真实双 SIM 手机、Android instrumentation 设备、生产 HTTPS/Web Push 授权环境或本地 Docker daemon；本地 Compose 只做配置解析。CI 的浏览器 smoke 和构建不替代这些环境验收。
- Android 后台调度和验证码读取受系统/厂商限制；dataSync 前台服务有时长限制，不能承诺全天即时。
- 短信正文以明文保存在中枢 MySQL、Android 私有数据库和备份中；传输加密，但首版没有 E2EE 或 SQL 字段加密。
- 历史永久保留；首版不支持 MMS/RCS、发送短信、多租户、数据清理或数据库回档 epoch 自动恢复。
- 首版只有初始 schema，没有旧版业务数据库升级路径；down migration 会销毁数据，绝不能用于生产回滚。

## 部署与回滚

仅建议在合成/非关键数据的隔离环境试用。完整首次部署、管理员配对、备份恢复和 HTTPS 代理步骤见 `docs/DEPLOYMENT.md`。

升级前先验证备份，并记录原 OCI 镜像；应用回滚只有在 schema 兼容时才能运行原镜像。此首版的 down migration 会删表，禁止将它当作回滚步骤。若不兼容，停止服务并将备份恢复到新的空数据卷；任何恢复/重建都必须由部署者确认目标数据卷。
