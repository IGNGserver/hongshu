# 鸿枢 v0.1.0-alpha.23

本版本重做 Android 客户端界面，主要是动效、设置结构和首页对话体验，并补充首次使用引导。版本仍属 alpha，为预发布版本，不是稳定版。服务端 API 与数据库结构没有变化。

## 本次更新

- **页面切换有动效**：进入对话或设置时横向过渡；系统返回手势会跟随手指预览上一页，松手完成或回弹。
- **设置按用途重组**：设置首页先列出需要处理的问题并直达对应页面，再分为中枢连接、短信采集、SIM 卡与号码、待上传短信、通知、后台运行、诊断信息和关于。开关点下即生效；需要权限的开关在授权后才打开，被拒绝时保持关闭并说明原因。
- **设置说明更易懂**：“广播、补漏、兜底、保活”等术语改为“实时接收、漏收检查、从通知读取、保持实时连接”；长说明收进“了解更多”；原始状态文字移到“诊断信息”，可一键复制（不含短信内容与凭据）。
- **中枢连接更清楚**：已连接时显示连接卡片，可修改连接或立即同步；新增“测试连接”，用于确认中枢地址可以访问（不校验密码）；地址格式即时校验，密码可显示或隐藏。
- **首页与对话**：搜索栏改为胶囊样式，设置按钮在有问题时显示角标；下拉刷新会等待同步真正完成，超时则提示已排队；同步异常和待上传短信以横幅提示；SIM 筛选按卡槽显示，会话行标注接收卡。
- **验证码一键复制**：识别到验证码的短信会显示“复制验证码”按钮；对话按日期分隔，回到最新消息更方便。
- **首次使用引导**：首页显示设置清单，依次完成连接中枢、选择这台手机的用途、设置 SIM 号码和保持实时连接；全部完成后自动隐藏。

## 升级与回滚

Android 数据库无需迁移，可直接覆盖安装。中枢服务端 API 与数据库 schema 无变化，升级中枢时可保持现有部署，只需拉取版本镜像并检查健康状态：

```bash
docker compose pull hub
docker compose up -d hub
curl --fail http://127.0.0.1:18473/healthz
```

如需回滚中枢，在 `.env` 中将镜像版本改回 `0.1.0-alpha.22`，再执行上述命令。Android 不支持直接降级安装；卸载会清除本地待同步队列，不建议通过卸载回滚 APK。

## 验证边界

本版本的自动化测试覆盖导航栈、设置状态判断、验证码识别、首次引导和界面截图渲染；发布工作流会重新执行仓库合同检查、真实 MySQL 集成、Go 测试与构建、Web 测试与构建，以及 Android 单测、lint、签名 APK 构建和 API 28/33/35 模拟器测试。

本版本尚未在真机上验证：预测性返回手势的实际手感、厂商系统（如澎湃 OS）中设置页的跳转、不同输入法下的表单布局，需要在目标设备上确认。
