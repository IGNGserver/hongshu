# 鸿枢 v0.2.0-alpha.5

本版本是跨设备短信同步与实时状态通知能力增强的 alpha 预览版，不是稳定版。升级前请备份数据库和部署 `.env`。

## 本次更新

- **验证码实时状态 / 灵动岛通知（Android 16+）**：
  - 当其他设备（非本机）收到验证码短信并通过中枢同步到本机时，以高优先级实时状态（Live Updates / 状态栏胶囊药丸）常驻展示验证码；
  - 严格避免与收到短信的手机自带系统（如小米/HyperOS、OriginOS、ColorOS）验证码弹窗冲突（本机收到短信不触发）；
  - Android 15 及以下设备优雅降级为高优先级标准常驻通知；
  - 通知自带“快捷复制”与“关闭”操作，点击复制后自动写入剪贴板并关闭通知，附带 10 分钟超时自毁保护；
  - 通知设置中新增专属控制开关，支持用户自主启闭。

## 升级与回滚

升级前做好数据库和 `.env` 备份，将 `.env` 中的 `HONGSHU_VERSION` 改为 `0.2.0-alpha.5`，执行 `docker compose pull hub` 和 `docker compose up -d hub`，再检查 `/healthz` 和客户端同步状态。本版本无数据库 schema 迁移变动。

如需回滚，可将 `HONGSHU_VERSION` 改回之前的版本重新部署即可。
