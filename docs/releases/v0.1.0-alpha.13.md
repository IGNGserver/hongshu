# 鸿枢 v0.1.0-alpha.13

本版本主要完善发布构建与自动化分发链路，并集中修复 Android 端设备设置、SIM 识别和短信同步体验问题。版本仍属 alpha，为预发布版本，不是稳定版。

## 变更与修复

- **发布镜像构建修复**：修正 `.dockerignore` 排除规则，确保生产容器镜像构建阶段正常包含 `web/build.mjs`。
- **私有 GHCR 发布恢复与检测**：在私有镜像仓库环境下使用 GitHub Packages API 准确校验标签与 digest 对应关系，并增加工作流级别的发布恢复入口。
- **设备名称保存**：首次连接和连接成功后都可保存设备名称；连接后改名复用原设备身份，不会重复创建设备凭据。
- **SIM 识别设置精简**：手动模式仅保留 SIM1 手机号、SIM2 手机号、自动扫描并填入号码和保存；自动模式隐藏手动输入并持续跟踪 SIM/号码变化，无法读取时不猜测归属。
- **同步控制精简**：实时广播页面仅保留同步本机短信、接收全部通知、短信同步状态、后台保活状态、通知接收状态和后台保活开关，并显示真实权限、连接和后台运行状态。
- **历史短信自动同步**：开启同步本机短信后自动采集全部可读取的历史收件箱短信，分批上传、断点续传、去重，不再要求用户手动导入；SIM 变化不会改写已捕获短信的历史接收号码。
- **运维与发布回归**：更新操作测试套件，验证私有包标签检测与故障模拟。

## 升级与回滚

中枢部署基于发布镜像标签（如 `0.1.0-alpha.13`）。升级时拉取新镜像并重启：

```bash
docker compose pull hub
docker compose up -d hub
curl --fail http://127.0.0.1:18473/healthz
```

如需回滚，在 `.env` 中使用上一版本镜像标签 `0.1.0-alpha.12` 并重新执行上述步骤。本版本包含 Android 本地数据库 v4→v5 迁移；迁移保留待传队列、SIM 映射和捕获账本，应用升级失败时可回退 APK，服务端数据库无需回滚。

## 验证边界

本机已完成仓库完整性校验、Go/MySQL 集成测试、Web 测试与构建、Android 单元测试/lint/APK 构建、API 35 模拟器 instrumentation 17 项测试及实际设置页 UI smoke。完整正式 Android 签名及 OCI 镜像构建将通过 GitHub Actions 发布工作流在隔离环境中验证。真实双卡/运营商换号和生产环境部署仍需目标设备验收。
