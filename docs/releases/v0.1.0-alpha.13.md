# 鸿枢 v0.1.0-alpha.13

本版本主要完善发布构建与自动化分发链路，修复容器镜像打包排除了 Web 构建脚本的问题，并改进私有 GHCR 环境下的标签检测与恢复流程。版本仍属 alpha，为预发布版本，不是稳定版。

## 变更与修复

- **发布镜像构建修复**：修正 `.dockerignore` 排除规则，确保生产容器镜像构建阶段正常包含 `web/build.mjs`。
- **私有 GHCR 发布恢复与检测**：在私有镜像仓库环境下使用 GitHub Packages API 准确校验标签与 digest 对应关系，并增加工作流级别的发布恢复入口。
- **运维与发布回归**：更新操作测试套件，验证私有包标签检测与故障模拟。

## 升级与回滚

中枢部署基于发布镜像标签（如 `0.1.0-alpha.13`）。升级时拉取新镜像并重启：

```bash
docker compose pull hub
docker compose up -d hub
curl --fail http://127.0.0.1:18473/healthz
```

如需回滚，在 `.env` 中使用上一版本镜像标签 `0.1.0-alpha.12` 并重新执行上述步骤。本版本不包含数据库 schema 变更，现有配置与数据保持兼容。

## 验证边界

本机已完成仓库完整性校验、操作与运维故障回归测试、Web 语法检查及构建。完整构建测试、正式 Android 签名及 OCI 镜像构建将通过 GitHub Actions 发布工作流在隔离环境中验证。
