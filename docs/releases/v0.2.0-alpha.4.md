# 鸿枢 v0.2.0-alpha.4

本版本是跨设备短信同步与验证码识别能力增强的 alpha 预览版，不是稳定版。升级前请备份数据库和部署 `.env`。

## 本次更新

- **验证码多格式识别优化**：
  - 增强 Token 切分与识别机制，全面支持单字母前缀（如 Google 的 `G-397783`）以及带连字符的分段验证码（如 Stripe `719-839`、`123-456`）；
  - 扩充关键词覆盖范围（如补充识别“动态口令”）；
  - 扩展前后文限定词与语法包裹容忍度（支持中英文引号 `""`、`''`、方括号 `[]`、中文括号 `【】` 以及自然语言限定连接结构，如 `是您的 Google 验证码`、`Use ... as your login code`）；
  - 将邻近匹配语法窗口适度放宽至 32 字符，避免倒装或品牌限定前缀被截断；
  - 严格保持对日期（如 `2026-10-16`）、时间、交易金额（如 `1234.50元`）等日常数字短信的排除逻辑，零误报。
- **双端规则与测试对齐**：
  - Go 服务端与 Android 客户端同步更新识别引擎，保证离线与在线处理结果 100% 契约一致；
  - 双端测试套件扩充，全面覆盖 Google、Stripe、Telegram、WhatsApp、Steam、Amazon、京东、华为、小米等主流平台验证码用例。

## 升级与回滚

升级前做好数据库和 `.env` 备份，将 `.env` 中的 `HONGSHU_VERSION` 改为 `0.2.0-alpha.4`，执行 `docker compose pull hub` 和 `docker compose up -d hub`，再检查 `/healthz` 和客户端同步状态。本版本无数据库 schema 迁移变动。

如需回滚，可将 `HONGSHU_VERSION` 改回之前的版本重新部署即可。
