# 鸿枢 v0.2.0-alpha.14

本版本在 v0.2.0-alpha.13 基础上，增加查看设备本机联系人显示。仍为 alpha 预览版，不是稳定版。

## 本次更新

- **Android**：可在设置中主动开启本机通讯录显示，为会话使用本机联系人姓名和头像，并在本地按姓名搜索；权限可随时撤销，联系人不上传、不修改短信发件号码或会话身份。
- **Web/PWA**：支持 Contact Picker 的安全浏览器可手动选择联系人，在本浏览器显示姓名/头像及本地搜索；可停用、清除，退出登录时清除。浏览器不支持该 API 时保留原显示。
- **隐私与兼容**：本机联系人与既有中枢别名分离，不进入中枢、AI、上传、设备同步或服务端数据库；没有数据库迁移。联系人照片无法读取时回退默认头像。
- **弱网与首屏**：保留 alpha.13 的首屏优先和离线应用壳改进。

## 升级与回滚

升级中枢时先备份数据库，将部署目录 `.env` 的 `HONGSHU_VERSION` 设为 `0.2.0-alpha.14`，然后运行：

```bash
docker compose pull hub
docker compose up -d hub
curl --fail http://127.0.0.1:18473/healthz
```

本版本不改数据库 schema；若中枢健康检查失败，可将 `HONGSHU_VERSION` 改回 `0.2.0-alpha.13` 并重启 hub。不要删除数据卷。Android 本地联系人偏好不改变短信数据库；PWA 所选联系人只保存在该浏览器本地，服务端回滚不会把它上传或同步。

## 验证

- 完整 CI 与设备验收边界见 [`docs/VALIDATION.md`](https://github.com/IGNGserver/hongshu/blob/main/docs/VALIDATION.md)。
- 用户真实 Android 通讯录授权/照片读取以及真实手机浏览器 Contact Picker 仍需设备验收；自动化夹具不代表厂商 ROM 或真实 Picker 已验收。
