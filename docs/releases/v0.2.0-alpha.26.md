# 鸿枢 0.2.0-alpha.26

本版本为 alpha 预览版，集中补全跨设备实时短信通知、验证码灵动/焦点通知与一键复制体验、精确未读角标对账以及进入软件即时显示最新消息的能力。无数据库 schema 迁移变更，可从 `0.2.0-alpha.24` / `0.2.0-alpha.25` 平滑升级。

## 本次更新

- **除来源设备外的全端通知**：Go 中枢下发 Web Push 与实时变更通知时按 `device_id` 排除消息原始上报设备；支持从上传设备以外的所有 Android 与 Web/PWA 终端接收来自鸿枢的新短信通知，默认展示完整发件人与正文。
- **验证码聚焦通知与一键复制**：
  - Android 端引入 `OtpNotificationManager` 与轻量前台化 `OtpCopyActivity`，支持 Android 16 Promoted Ongoing、澎湃 OS 焦点通知参数（`miui.focus.param`）及大文本展开样式；点击“复制验证码”即可在前台获取剪贴板焦点并直接完成复制。
  - Go 中枢 AI 异步复核识别出验证码后可再次推送升级通知，将普通新短信通知自动替换为验证码一键复制通知。
  - Web 与 iOS 16.4+ 主屏幕 PWA 通过标准 Web Push 推送验证码标题、正文与复制操作按钮，打开后零刷新定位对应会话，并在顶部验证码胶囊（`otpBanner`）及会话列表展示一键复制按钮。
- **真实未读角标与已读撤销**：
  - Go 中枢与 Android 本机同步计算按设备维度排除本人上传短信，统一通知计数语义；Android 保活前台通知移入独立无角标渠道 `connection_silent` 并固定 `setNumber(0)`。
  - 任一设备标记会话已读或全部已读后，Web Push 同步更新/清空系统应用角标，Android/PWA 客户端同步撤销已投递通知。
- **进入软件即时刷新与稳定保活**：
  - 短信上传响应即完成摘要与计数物化；Android `MainActivity.onResume`、PWA `pageshow`/`focus` 与 WebSocket 握手立即触发增量同步并优先渲染首屏列表；修复 `RealtimeService` 在 401/停止等早退路径触发 `ForegroundServiceDidNotStartInTimeException` 的竞态问题。

## 已知边界

- iOS 受系统平台限制仅支持加入主屏幕的 PWA（iOS/iPadOS 16.4+）接收标准 Web Push 通知与系统角标，不支持系统级灵动岛 Live Activity；打开 PWA 后顶部会显示验证码一键复制横幅。
- Android 16 实况通知与小米澎湃 OS 焦点通知依赖系统/机型支持，未支持机型自动降级为高优先级系统通知与“复制验证码”动作按钮。
- Android 与 Go/MySQL/PWA 已完成 CI 模拟器矩阵（API 28/33/35）与 Chromium Service Worker 自动化校验；小米/澎湃 OS 与 iOS 真机实况样式仍建议现场抽测确认。

## 升级与回滚

中枢无需新增数据库迁移：在部署 `.env` 中将 `HONGSHU_VERSION` 更新为 `0.2.0-alpha.26`，执行 `docker compose pull hub && docker compose up -d hub` 即可升级。如需回滚，只需将 `.env` 中的 `HONGSHU_VERSION` 改回原版本（如 `0.2.0-alpha.24` 或 `0.2.0-alpha.25`）并重新执行 `docker compose up -d hub`。Android 直接覆盖安装同签名 APK，不清除已有数据。
