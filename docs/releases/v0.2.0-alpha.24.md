# 鸿枢 0.2.0-alpha.24

本版本为 alpha 预览版。这是一次以正确性、可观测性和性能为主的质量整改，不引入破坏性 API 变更。

## 本次更新

- 会话分页新增 head/epoch 围栏的 keyset 游标；旧 `offset` 客户端继续可用，同时传 `offset` 与 `cursor` 返回 400。每页查询与提交头处于同一快照，页面间 head/epoch 变化即废弃整条游标链。
- 标读在提交与响应之间使用同一事务快照；只有有效水位推进才使其他客户端失效，未读计数加入版本化缓存与 singleflight。
- AI 分类区分「单条消息永久错误」与「全局配置/鉴权/限流错误」，未知 400 连续三次熔断；调度改为类型化休眠，结果落库失败保留 durable lease 并计数。
- Push 投递按 endpoint+p256dh+auth 全键围栏，永久 4xx 只丢弃该条任务，保留消息与订阅；支持 `Retry-After` 的 HTTP-date，错误体读取有界。
- 新增 `GET /api/ops`（需认证）：版本、运行时长、连接池、schema 版本与 dirty、Push/AI 计数与最后循环时间、worker 存活、订阅数。只输出计数、时长与布尔值。
- 历史页与补拉页改为先按索引物化一页再 join，10 万条规模下由 113ms/115ms 降到 0.58ms/1.29ms；新增迁移 015 删除被完全覆盖的两条冗余索引。
- 进程关停改为有界 HTTP drain + worker 取消/join + 资源关闭的有序流程。

## 客户端

- Android：上传 ACK 按实际发送的 `sent_fingerprint` 条件确认；广播短信在 `onReceive` 返回前落盘；实时同步使用可续租的有界 wakelock；OkHttp 与协程取消联动；OTP 复制前先消费持久意图；兼容 API 26/27 的剪贴板清理。
- Web/PWA：服务器优先退出、跨标签认证协调、head-fenced keyset、Service Worker 旧壳安全回收；Push 轮换检查响应并自动恢复。
- 协议：Go/Web/Android 共享错误码与重试处置合同（`protocol/error-codes.v1.json`），三端在 CI 中校验。

## 运维

- 外部 MySQL 迁移改用镜像内 `/app/migrations`；备份仅依赖数据库健康，新增独立的外部库备份单元。
- 备份支持单轮超时、原子状态、超龄健康检查和保留策略；初始化脚本先写 0600 临时文件，全部校验通过后才原子发布 `.env`。
- 镜像默认构建 `linux/amd64,linux/arm64`；稳定 `latest` 只在 SemVer 前进时移动。
- CI/Release 固定全部 Action 与基础镜像摘要，增加凭据扫描、依赖审查与镜像漏洞门禁。

## 已知边界

- 真机（锁屏/Doze、双卡、系统扣留短信）、真实 Web Push 到达、外部 AI 端点与容器镜像演练未在本版本验证。
- 仓储层与 Web 会话状态机的结构性拆分未实施，需真机/浏览器回归后再进行。
