# 鸿枢 v0.1.0-alpha.12

本版本发布鸿枢新的项目品牌图标，统一 Web/PWA 与 Android 客户端的应用图标、通知图标和 PWA 推送资源。版本仍属 alpha，为预发布版本，不是稳定版。

## 视觉更新

- 采用新的 `icon2` 品牌图标：以简洁的短信通信轮廓为主，并将鸿鸟翼形融入同一标志，保留深靛蓝、低光泽、克制的轻拟物质感。
- Web/PWA 更新 favicon、安装图标、推送通知图标及主题色；升级 Service Worker 缓存版本，确保已安装 PWA 获取新图标。
- Android 更新启动图标；通知栏继续使用适配 Android 单色要求的同品牌白色图形资源。
- 移除旧版绿色短信图形生成逻辑，改为以仓库内 512px 主图标生成 Web 192px 派生资源，避免后续命令恢复旧品牌。
- 修复同步任务已在运行时仍被重复追加的问题，避免网络失败重试期间产生并行同步任务。

## 升级与回滚

中枢部署基于发布镜像标签（如 `0.1.0-alpha.12`）。升级时拉取新镜像并重启：

```bash
docker compose pull hub
docker compose up -d hub
curl --fail http://127.0.0.1:18473/healthz
```

如需回滚，使用上一版本镜像标签 `0.1.0-alpha.11` 执行同样的拉取与重启步骤。图标资源不涉及数据库迁移，既有配置和数据保持兼容。

## 验证边界

本机已完成仓库校验、Web 测试/语法检查/构建、Android 单元测试/lint/debug APK 构建和图标资源校验。Go race/vet/build、真实 MySQL 集成测试及浏览器 smoke 测试由发布工作流在隔离 CI 环境中执行；本机未安装 Go 工具链，且没有可用的测试 MySQL 实例。
