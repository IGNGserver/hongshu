# 鸿枢 v0.2.0-alpha.10

本版本在 v0.2.0-alpha.9 基础之上，完善 Web/PWA 在 Safari（iOS/iPadOS 主屏幕添加、macOS Sonoma 添加到程序坞）及各平台启动器的图标兼容性与元标签支持。仍为 alpha 预览版，不是稳定版。

## 本次更新

- **全平台多尺寸图标与 Safari 适配**：
  - 派生生成标准多规格 iOS 图标：`apple-touch-icon.png` (180x180 iPhone)、`apple-touch-icon-167.png` (167x167 iPad Pro)、`apple-touch-icon-152.png` (152x152 iPad)；
  - 补充 192x192 的 Maskable 圆角安全区图标（`icon-maskable-192.png`），与 512x512 组成双阶梯，消除部分 Android 设备因缺少 192px maskable 图标导致的启动器圆角裁切异常；
  - 补充桌面端 Favicon 兜底图标：`favicon-32.png` 与 `favicon-16.png`。
- **HTML 头部元标签声明与 WebClip 强化**：
  - 新增 `apple-mobile-web-app-capable`、`apple-mobile-web-app-status-bar-style` 与 `apple-mobile-web-app-title` 声明；
  - 显式声明各规格 `apple-touch-icon` 与 `favicon` 标签；
  - 更新 Web App Manifest 纳入新图标规格。
- **中枢静态白名单与离线预缓存**：
  - Go 中枢静态路由白名单放行新增图标文件；
  - Service Worker 离线壳预缓存清单同步更新。

## 升级与回滚

中枢升级：将部署目录 `.env` 中的 `HONGSHU_VERSION` 修改为 `0.2.0-alpha.10`，执行 `docker compose pull hub` 与 `docker compose up -d hub`。本版本服务端无数据库迁移。已添加到桌面/主屏幕的 PWA 客户端建议删除后重新从浏览器“添加到主屏幕”，以使系统刷新应用快捷方式图标。

如需回滚，可将 `HONGSHU_VERSION` 改回 `0.2.0-alpha.9` 并重新拉起容器。
