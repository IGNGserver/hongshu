# 鸿枢 v0.2.0-alpha.22

本版本为 alpha 预览版。

## 本次更新

- Android 客户端直接读取 GitHub 仓库发布的静态更新清单并下载 APK，不再通过鸿枢中枢转发检查与下载请求。
- 增加稳定版与预览版通道选择；预览版通道可接收预发布和正式版本，稳定版通道只接收正式版本。
- 为检查结果加入缓存和退避，减少重复请求并缓解限流；切换通道、检查和下载均阻止安装低于当前版本的版本。
- 下载前验证版本、应用包身份与签名，避免安装不匹配的 APK。

## 快捷下载

- [直接下载 Android APK](https://github.com/IGNGserver/hongshu/releases/download/v0.2.0-alpha.22/Hongshu-Android-0.2.0-alpha.22.apk)
- [下载部署文件包](https://github.com/IGNGserver/hongshu/releases/download/v0.2.0-alpha.22/hongshu-v0.2.0-alpha.22-deployment.tar.gz)
- 中枢镜像：`ghcr.io/igngserver/hongshu:0.2.0-alpha.22`

## 升级说明

升级中枢前请备份数据库和 `.env`。应用内更新只允许升级；服务端回退请按数据库兼容性、备份与部署流程单独处理，不要清除数据库卷。

## 验证

- 发布工作流会重新运行服务端、Web/PWA 和 Android 验证，并检查签名 APK、部署归档及镜像。
- CI 与模拟器不能代替真机签名安装、覆盖升级和不同厂商后台策略验收。

## 已知限制

- 本版本仍为 alpha 预览版，不是稳定版；真实设备的安装与后台行为仍需验收。
