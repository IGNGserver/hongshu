# 鸿枢 v0.1.0-alpha.6

本版本重构了发布交付流并升级了 Material 3 Expressive 界面。本版本是 GitHub **Pre-release**，仍属 alpha，不是稳定版。

## 新增与调整

- **Android 客户端**：采用项目独立的正式证书签名（非 debug），通过安全存储的私有密钥库生成正式安装包；界面全面升级为 Material 3 Expressive 风格，优化了动效、状态切换与视觉层级。
- **Release 资产精简**：GitHub Release 资产聚焦于 Android 客户端正式安装包（`hongshu-v0.1.0-alpha.6-android.apk`）与校验文件，不再堆积散装二进制文件。
- **中枢容器镜像发布**：中枢镜像自动构建并推送到 GitHub Container Registry（`ghcr.io/igngserver/hongshu:0.1.0-alpha.6`）。用户可通过 Docker Compose 直接拉取镜像运行，无需从源码编译。
- **Web/PWA 体验**：采用 Material 3 Expressive 设计规范，增加波浪形非确定进度条、优化的状态层和自适应布局。

## 升级与回滚

中枢部署基于发布镜像标签（如 `0.1.0-alpha.6` 或 `latest`）。升级时拉取新镜像并重启即可：
```bash
docker compose pull hub
docker compose up -d hub
```

回滚时在 `.env` 中指定旧版 `HONGSHU_VERSION`（如 `0.1.0-alpha.5`）并重新运行 `docker compose up -d hub`。数据库结构保持向后兼容，不需要额外迁移回滚。保留数据库卷与备份，不要对生产数据卷执行 `docker compose down -v`。

## 验证边界

发布工作流已运行真实隔离 MySQL 上的 Go race/vet 集成测试、浏览器 smoke 测试、Android 单元测试/lint 以及 Release 签名验证。实际公网可达性与 Android 真机短信收发仍需部署者单独验收。
