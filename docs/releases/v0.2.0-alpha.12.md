# 鸿枢 v0.2.0-alpha.12

本版本在 v0.2.0-alpha.11 基础之上，对前端短信展示进行以用户本人为中心的交互优化，完善跨设备发出短信的合并聚类体验。仍为 alpha 预览版，不是稳定版。

## 本次更新

- **前端跨设备发出短信合并聚类**：
  - 调整消息聚合算法（`clusterMessages`），将“发出的短信”（`direction === "out"`）以用户本人为本进行聚类；
  - 无论从哪台设备/哪张 SIM 卡发出，在连贯时间段内的发出短信统一聚合在右侧我方气泡组中，呈现一致的第一人称对话体验；
  - 接收短信（`direction === "in"`）继续严格按各来源设备与对端分别聚类；
  - 补充并更新前端跨设备发出短信聚类单元测试。

## 升级与回滚

中枢升级：将部署目录 `.env` 中的 `HONGSHU_VERSION` 修改为 `0.2.0-alpha.12`，执行：
```bash
docker compose pull hub
docker compose up -d hub
```

如需回滚，可将 `HONGSHU_VERSION` 改回 `0.2.0-alpha.11` 并重新拉起容器。本版本无破坏性数据库变更。
