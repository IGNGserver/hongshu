# 鸿枢 v0.2.0-alpha.6

本版本是引入未读消息管理、跨设备已读同步与角标支持的 alpha 预览版，不是稳定版。升级前请备份数据库和部署 `.env`。

## 本次更新

- **未读消息跟踪与跨设备已读同步**：
  - 中枢数据库新增 `009_read_watermarks` 迁移，维护全局已读水位线与会话级已读游标；
  - 老版本平滑升级：初始水位取自当前最大消息 ID，存量历史消息默认已读，升级后未读数从 0 起步；历史导入消息天然不计入未读；
  - 新增 `POST /api/messages/read` 接口，支持一键全部已读或按发件人会话标记已读，已读状态通过 WebSocket 实时广播。
- **Web / PWA 体验提升**：
  - 收件箱顶部工具栏增加“全部标记为已读”按钮；
  - 会话列表项增加未读数量徽标；
  - 支持浏览器 App Badging API（`navigator.setAppBadge` / `clearAppBadge`）与网页标题动态徽标；
  - 进入会话详情自动触发该会话已读。
- **Android 客户端同步增强**：
  - 本地 SQLite 同步升级（version 8），支持本地未读计数与会话已读游标；
  - 顶部搜索栏增加“全部标记为已读”快捷操作；
  - 会话列表项显示 Material 3 未读徽标，进入会话详情自动标记已读并上报中枢；
  - 通知与角标联动：未读消除时自动取消未读短信系统通知，桌面图标角标同步清除。

## 升级与回滚

升级前做好数据库和 `.env` 备份，将 `.env` 中的 `HONGSHU_VERSION` 改为 `0.2.0-alpha.6`，执行 `docker compose pull hub` 和 `docker compose up -d hub`，再检查 `/healthz`、`schema_migrations` 和客户端同步状态。中枢会自动应用 `009_read_watermarks` 迁移；迁移不会删除历史短信。

如需回滚，可将 `HONGSHU_VERSION` 改回之前的版本重新部署，并可选择按需执行 `009_read_watermarks.down.sql` 回滚新增表。
