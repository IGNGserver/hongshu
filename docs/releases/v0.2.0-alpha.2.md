# 鸿枢 v0.2.0-alpha.2

本版本是 Web 端重设计的 alpha 预览版，不是稳定版。Web 界面向 Google Messages 网页版和 Android 客户端看齐；中枢 API、数据库结构和同步协议没有变化，Android 客户端功能与 v0.2.0-alpha.1 相同。

## 本次更新

- **项目图标恢复显示**：标签页图标和应用内图标不再是空白；安装为 PWA 时使用带安全边距的自适应图标，并新增 iOS 主屏幕图标。中枢同步放行了这些图标文件，避免离线应用壳安装失败。
- **新布局**：去掉左侧导航栏，改为“列表 + 浮起的会话卡片”。设置从列表顶部的齿轮进入，“设备”并入设置的“设备与 SIM”。颜色直接取自 Android 端主题，浅色和深色都与手机一致。
- **会话与短信**：头像规则与 Android 相同（联系人首字、号码人形图标、服务号饼干形）；会话列表显示 SIM 名称和时间；同一设备 5 分钟内的短信合并成一簇，时间和来源只显示一次；正文里的网址可以点击；复制和调整分类收进气泡旁的悬停工具。
- **验证码卡片**：等宽大号显示验证码，一键复制并在原地显示“已复制”；按短信标注的有效期显示剩余时间。
- **筛选与列表**：分组芯片排成一行；SIM 和设备合并成一个“筛选”菜单；会话列表滚动到底部时自动加载更早的会话，不再需要翻页。
- **设置与登录**：设置改为与 Android 一致的分组列表；新增“主题：跟随系统 / 浅色 / 深色”，只保存在当前浏览器；AI 设置改用开关和带标签的输入框；登录页可以显示密码，明文 HTTP 警告更醒目。
- **动效**：新短信到达时被顶下去的会话平滑让位；往上翻历史时出现“↓ 最新”按钮，新短信到达时显示“新短信”，不会强行把页面滚到底；手机端进入和返回页面有方向一致的转场。系统开启“减少动态效果”时，这些动画都会关闭。
- **修复**：AI 设置里的复选框不再被拉成大方块；会话列表不再在每次刷新时闪动；手机端进入会话后隐藏底部导航，浏览器返回键可以回到列表。

## 升级与回滚

本版本没有新的数据库迁移。升级前仍建议备份数据库和部署 `.env`，然后把 `.env` 中的 `HONGSHU_VERSION` 改为 `0.2.0-alpha.2`，执行 `docker compose pull hub` 和 `docker compose up -d hub`，并检查 `/healthz`。已打开的浏览器在下次刷新后才会换成新界面；如果一直显示旧界面，关闭所有鸿枢标签页后重新打开。

回滚时把 `HONGSHU_VERSION` 改回 `0.2.0-alpha.1`，重新执行 `docker compose up -d hub` 即可，数据和设备授权不受影响。浏览器里保存的主题偏好只是一个本地设置，回滚后不再生效，可以忽略。

## 验证边界

四个 Web 重设计 PR（IGNGserver/hongshu#52、#53、#54、#55）的 Hongshu validation CI 均已通过隔离 MySQL、Go/Web 检查、Playwright 浏览器烟测以及 API 28/33/35 Android 模拟器测试。发布工作流还会对本版本重新执行服务端、Web、Android 签名构建和资产校验后再公开发布。

界面只在合成数据上做过桌面宽度和手机宽度的走查；还没有在真机浏览器、iOS Safari 和真实的大量历史数据上验证。
