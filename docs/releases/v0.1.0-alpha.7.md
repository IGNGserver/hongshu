# 鸿枢 v0.1.0-alpha.7

本版本移除了配对码机制，所有设备统一通过中枢密码进行认证。本版本是 GitHub **Pre-release**，仍属 alpha，不是稳定版。

## 新增与调整

- **移除配对码机制**：全面移除一次性配对码生成及基于配对码的设备注册链路；新增数据库迁移 `004_remove_pairings` 清理 `pairings` 表。
- **统一认证模型**：所有客户端（Web 浏览器与 Android 客户端）统一调用 `POST /api/login` 传入中枢密码接入中枢；登录成功后自动颁发 `hongshu` HttpOnly Cookie 会话，并返回设备 token。
- **Android 客户端**：设置面板移除配对码输入，直接使用中枢密码连接中枢；支持基于 Cookie 会话与 Token 双重凭证认证。
- **Web 客户端**：设备管理页面移除配对码生成卡片，更新为统一密码连接提示；精简错误状态映射。

## 升级与回滚

中枢部署基于发布镜像标签（如 `0.1.0-alpha.7` 或 `latest`）。升级时拉取新镜像并重启：
```bash
docker compose pull hub
docker compose up -d hub
```

升级后中枢会自动应用 `004_remove_pairings.up.sql` 迁移移除 `pairings` 表。回滚到旧版本前需运行 `004_remove_pairings.down.sql` 重建该表。不要删除 MySQL 数据卷。

## 验证边界

发布工作流已运行真实隔离 MySQL 上的 Go race/vet 集成测试、浏览器 smoke 测试、Android 单元测试/lint 以及 Release 签名验证。
