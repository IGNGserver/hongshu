# 鸿枢 v0.2.0-alpha.1

本版本为短信验证码提取与可选 AI 分组的 alpha 预览版，不是稳定版。AI 默认关闭；开启前会说明历史和新增的非验证码短信正文将发送到管理员配置的模型服务。

## 本次更新

- **验证码提取**：客户端与中枢使用保守规则识别短信中的验证码；有歧义时不提升为验证码。验证码可手动复制，不会自动复制、认证发送方或删除原短信。
- **可选 AI 分组**：启用后可按个人、通知、推广、垃圾和待分析查看短信；“全部”仍是完整时间线。未启用 AI 时，全部、验证码和其他短信仍可查看。
- **分析与收件解耦**：短信先保存并同步，分类在后台处理。AI 关闭、服务不可用或分类失败都不会阻塞收件、同步与阅读；验证码不会发送给 AI。
- **人工控制**：手动分类优先于后台结果；失败项可重试，垃圾短信可以恢复，系统不会自动删除短信。
- **隐私与运维**：AI 密钥加密保存；默认限制公网 HTTPS 地址，访问本地模型需管理员显式配置精确主机名白名单。分类调用有速率与额度限制，脱敏不保证匿名。
- **兼容迁移**：中枢新增 `006` 分析元数据迁移，Android 新增独立分析元数据存储；原始短信、上传队列和同步游标保持分离。旧客户端可忽略新增分析字段。

## 升级与回滚

升级前先备份数据库和部署 `.env`。若启用 AI，必须将 `HONGSHU_AI_SECRET` 与数据库备份一起安全保存；缺失该密钥时，已保存的 AI API 密钥无法解密。选择固定版本 `HONGSHU_VERSION=0.2.0-alpha.1`，拉取镜像并重建中枢后，再升级 Android 客户端。中枢启动时自动应用 `006` 迁移，保留原始短信；AI 仍保持关闭，需在 Web 设置中另行配置并明确启用。

回滚前先关闭 AI。服务端可在 schema 兼容前提下改回上一版固定镜像；请保留 `006` 新增表，不要执行其 down 迁移。Android 不支持直接降级安装，不要通过卸载来回滚，以免清除本机待同步短信。

## 验证边界

功能 PR 的 [Hongshu validation CI](https://github.com/IGNGserver/hongshu/actions/runs/38914238712) 已通过隔离 MySQL、Go/Web 检查及 API 28/33/35 Android 模拟器测试。发布工作流还会对本版本重新执行服务端、Web、Android 签名构建和资产校验后再公开发布。

测试使用合成短信与本地模拟模型；真实模型的分类质量、计费、真实短信权限限制、真机行为及生产环境升级尚未验证。AI 分类不应视为反诈保证。
