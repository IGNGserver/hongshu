# 鸿枢 v0.1.0-alpha.20

本版本加固跨设备短信同步全链路，修复队列停滞、上传确认误关联、异常短信阻塞和实时/历史调度问题。版本仍属 alpha，为预发布版本，不是稳定版。

## 本次更新

- **上传确认更安全**：服务端 ACK 增加消息指纹；客户端校验整组 ACK、消息指纹、非负且有效的消息 ID，并支持 ACK 乱序，避免错误确认或误删本地队列。
- **非法短信隔离**：对明确的 `400 invalid_message` 批次执行二分定位，只阻塞单条非法短信；网络、权限和其他协议错误不会被误判为短信内容非法。
- **实时与历史公平调度**：实时短信优先上传，历史续传定期获得机会；单轮限量、成功未排空时立即安排后继任务，异常继续使用 WorkManager 退避重试。
- **SIM 与通知关联更稳健**：SIM 注册按接收器和订阅 ID 去重；通知去重同时校验发送方、正文、时间窗口、兼容 SIM 和唯一候选，歧义时保留重复，不覆盖已有号码或订阅快照。
- **故障隔离与状态准确**：联系人刷新失败不再阻断短信下拉；首页、账户页和本地队列分别展示总数、可上传、待确认号码和异常统计，避免把“待映射”误报成当前可上传。
- **协议和测试同步**：补充 ACK 指纹、调度、通知去重、联系人故障和队列统计合同，并覆盖 Android、Go、Web、真实 MySQL 及 API 28/33/35 模拟器验证。

## 升级与回滚

Android 数据库无需迁移，可直接覆盖安装；中枢服务端 API 与数据库 schema 无新增迁移。升级中枢时使用版本镜像并检查健康状态：

```bash
docker compose pull hub
docker compose up -d hub
curl --fail http://127.0.0.1:18473/healthz
```

如需回滚中枢，在 `.env` 中将镜像版本改回 `0.1.0-alpha.19`，再执行上述命令。Android 不支持直接降级安装；卸载会清除本地待同步队列，不建议通过卸载回滚 APK。

## 验证边界

发布工作流会重新执行仓库合同检查、真实 MySQL 集成、Go race/vet/build、Web 测试与构建、浏览器冒烟、Android 单测/lint/签名 APK 构建及 API 28/33/35 模拟器测试。本版本仍未在目标真机上验证真实双卡/PDU、目标 ROM 通知字段、重启与离线恢复、实际 WorkManager 退避行为和 Push 可达性；模拟器结果不能替代这些实测。
