# 鸿枢 v0.1.0-alpha.22

本版本调整 GitHub Release 交付资产：Android 安装包采用统一品牌文件名，移除不再作为独立下载物发布的 Linux 中枢工具包，保留无源码部署文件包。版本仍属 alpha，为预发布版本，不是稳定版。

## 本次更新

- **统一 Android 下载文件名**：正式签名 APK 命名为 `Hongshu-Android-0.1.0-alpha.22.apk`，便于从 Release 直链识别客户端和版本。
- **精简 Release 资产**：Release 仅提供 Android APK 和部署文件包；中枢服务继续通过 GHCR 版本镜像交付，VAPID/healthcheck 等工具仍随源码和容器构建使用，不再单独打包下载。
- **保留无源码部署路径**：部署文件包继续包含 Compose 文件、初始化、备份/恢复脚本和部署文档，不要求用户取得项目源码。

## 升级与回滚

Android 客户端无数据库迁移，可直接覆盖安装；中枢服务端 API 与数据库 schema 无变化。升级中枢时使用 `0.1.0-alpha.22` 镜像并检查健康状态：

```bash
docker compose pull hub
docker compose up -d hub
curl --fail http://127.0.0.1:18473/healthz
```

如需回滚中枢，在 `.env` 中将镜像版本改回 `0.1.0-alpha.21`，再执行上述命令。Android 不支持直接降级安装；卸载会清除本地待同步队列，不建议通过卸载回滚 APK。

## 验证边界

发布工作流会重新执行仓库合同检查、真实 MySQL 集成、Go race/vet/build、Web 测试与构建、浏览器冒烟、Android 单测/lint/签名 APK 构建及 API 28/33/35 模拟器测试。Release 资产和下载链接由发布脚本在上传前严格校验；本版本未在目标真机上进行额外验收。
