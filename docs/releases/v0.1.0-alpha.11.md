# 鸿枢 v0.1.0-alpha.11

本版本重构并规范了 Android 客户端与 Web 端的视觉风格，全面剥离不符合短信聚合同步平台定位的 Google Messages 与 Gemini 元素，回归鸿枢原生品牌与极简设置，并优化了 Web 端 Material 3 Expressive 排版。本版本是 GitHub **Pre-release**，仍属 alpha，不是稳定版。

## 新增与调整

- **Android 客户端视觉归正与去 Google 化**：
  - 应用标题由通用的“信息”更正为项目正式名称“**鸿枢**”；
  - 移除首页右上角仿 Google 账号的圆形彩色头像，替换为标准的设置齿轮与同步图标；
  - 移除不具备聊天功能的 Google Extended FAB“开始聊天”以及仿 Gemini AI 星芒图标的悬浮按钮，同步动作回归顶栏与设置面板；
  - 设置面板顶部设备卡片移除虚假的“Pro · 已连接中枢”徽章与误导性多账号切换箭头，采用手机硬件图标展示真实设备型号与连接状态；
  - 补齐“关于鸿枢”子页面，详细展示项目自部署定位与技术架构；
  - 优化设置各选项文案，提高配置项可读性。
- **Web 端体验提升**：
  - 采用 Material 3 Expressive 现代排版规范；
  - 增强会话流式查看、多 SIM 筛选与设备管理体验。

## 升级与回滚

中枢部署基于发布镜像标签（如 `0.1.0-alpha.11`）。升级时拉取新镜像并重启：
```bash
docker compose pull hub
docker compose up -d hub
```

本版本向后兼容既有配置与数据库结构，无需数据库迁移。

## 验证边界

发布工作流已运行真实隔离 MySQL 上的 Go race/vet 集成测试、浏览器 smoke 测试、Android 单元测试/lint 以及 Release 签名验证。
