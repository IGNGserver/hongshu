# 鸿枢 v0.1.0-alpha.15

本版本主要带来 Android 端后台实时保活与最近任务隐藏支持，优化 Web 消息工作区交互，并增强实时短信采集的可靠性。版本仍属 alpha，为预发布版本，不是稳定版。

## 变更与修复

- **Android 最近任务隐藏**：提供独立且默认关闭的“不在最近任务列表显示”设置，基于当前任务调用 `setExcludeFromRecents`，可随时撤回恢复；首页返回退入后台，避免结束任务或影响厂商任务锁定关联。
- **Android 前台服务类型适配**：Android 14+ 跨设备实时连接使用 `remoteMessaging` 消息前台服务类型；旧系统保留 `dataSync` 兼容路径，避免 Android 15+ 受到 24 小时内累计 6 小时的后台运行限制。
- **Android 连接通知与恢复策略**：前台连接通知如实反映 WebSocket 握手、断网、重连状态；支持普通回收后 `START_STICKY` 空 Intent 恢复与网络重连；开机恢复需显式开启且凭据有效才拉起；主动停止持久关闭。
- **Android 低版本兼容**：`Store` 显式实现 `Closeable`，修复 Android 8 与 9 下 `SQLiteOpenHelper` 未实现 `AutoCloseable` 导致的 Kotlin `use` 运行时异常。
- **Web 端体验提升**：精简并重构消息工作区与会话列表，优化长历史滚动与设置抽屉交互。
- **短信捕获可靠性增强**：收件箱扫描与广播共享捕获账本，异常号码独立标记并可重置重试，SIM 变化时保留旧卡快照与未发送队列。

## 升级与回滚

中枢部署基于发布镜像标签（如 `0.1.0-alpha.15`）。升级时拉取新镜像并重启：

```bash
docker compose pull hub
docker compose up -d hub
curl --fail http://127.0.0.1:18473/healthz
```

如需回滚，在 `.env` 中使用上一版本镜像标签 `0.1.0-alpha.14` 并重新执行上述步骤。
