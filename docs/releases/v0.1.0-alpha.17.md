# 鸿枢 v0.1.0-alpha.17

本版本优化 Android 客户端的设置页沉浸式布局与多级返回体验，加入与系统侧滑方向一致的预测式返回动画。版本仍属 alpha，为预发布版本，不是稳定版。

## 本次更新

- **设置页 edge-to-edge**：设置页改为同一 Activity 内的全屏目的地，背景延伸至状态栏区域，顶部栏单独使用安全内边距，消除状态栏下方空隙。
- **统一导航栈**：会话详情、搜索和设置子页使用真实目的地栈；从“本机待同步短信”进入 SIM 设置后，返回会回到待同步短信页，不直接跳回首页。
- **预测式返回**：接入 AndroidX `PredictiveBackHandler`，左侧右滑时页面向右退出，右侧左滑时页面向左退出；取消手势不会改变导航状态。
- **导航状态测试**：新增设置层级、会话替换和关闭设置流程的 JVM 测试。

## 升级与回滚

中枢部署基于发布镜像标签（如 `0.1.0-alpha.17`）。升级时拉取新镜像并重启：

```bash
docker compose pull hub
docker compose up -d hub
curl --fail http://127.0.0.1:18473/healthz
```

如需回滚，在 `.env` 中使用上一版本镜像标签 `0.1.0-alpha.16` 并重新执行上述步骤。
