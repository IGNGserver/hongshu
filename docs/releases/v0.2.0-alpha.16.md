# 鸿枢 v0.2.0-alpha.16

本版本在 v0.2.0-alpha.15 基础上，修复 macOS Safari 添加网页 App 后图标回退为系统首字母占位图的问题。仍为 alpha 预览版，不是稳定版。

## 本次更新

- **macOS Safari 网页 App 图标**：manifest 新增 `1024×1024` 的 `any` 与 `maskable` 图标，并将 1024 maskable 放在首位。Safari 现在有足够高分辨率的 full-bleed 源生成程序坞/启动台/Quick Look 图标，不再回退为深色方块加“鸿”字的系统占位图。
- **图标兜底**：HTML 优先声明 1024/512/192 PNG favicon，补充多尺寸 `/favicon.ico` 与 `apple-touch-icon-precomposed.png`；iOS 主屏幕图标继续提供 180/167/152。
- **构建与服务端**：build 校验 1024 any/maskable，Service Worker 预缓存新图标，Go 静态白名单放行；新增测试逐条请求 manifest 图标、用 `image/png` 解码并核对声明尺寸。
- **兼容性**：没有数据库迁移、API 变更或同步协议变更；已有短信、已读状态、设备身份、订阅和部署数据不变。
- **重新添加提示**：Safari 只在“添加到程序坞/主屏幕”时抓取并缓存图标。升级后需要删除旧的网页 App，再重新添加一次，才会看到新图标；直接打开旧 App 不会触发重取。
- 1024 图标由仓库内 512 主图标 Catmull-Rom 上采样；后续有原生 1024 设计稿时可直接替换，不影响接口。

## 升级与回滚

升级中枢前先备份数据库和 `.env`，把部署目录的 `HONGSHU_VERSION` 设为 `0.2.0-alpha.16`，然后运行：

```bash
docker compose pull hub
docker compose up -d hub
curl --fail http://127.0.0.1:18473/healthz
```

本版本不改数据库 schema；若健康检查失败，把 `HONGSHU_VERSION` 改回 `0.2.0-alpha.15` 并重启 hub，不要删除数据卷。数据库、备份和既有设备授权不受影响。

Web Push 仍需要 HTTPS、`VAPID_PUBLIC_KEY`/`VAPID_PRIVATE_KEY` 和真实的 `VAPID_SUBJECT`。已有订阅无需因本版本轮换密钥；iOS 用户必须从主屏幕 Web App 打开后授权，Safari 标签页没有后台推送。
