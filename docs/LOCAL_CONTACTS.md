# 本机联系人显示

## 边界

联系人只装饰当前查看设备上的短信界面：会话列表、详情名称、头像和姓名搜索。
即使短信来自另一台手机，也只匹配查看设备的通讯录。不修改发件地址、会话键、
短信指纹、分类、已读水位或上传 JSON；不同号码不会因为属于同一联系人而合并。
姓名、照片、联系人标识和照片 URI 不进入中枢、AI、日志或设备同步。
已有 `/contacts` 中枢别名保持兼容，但与本机通讯录完全分离；本功能不调用其写接口。

## Android

默认关闭，在设置中主动开启时申请 READ_CONTACTS；拒绝不影响短信功能。
使用系统 PhoneLookup，并对返回号码再次做完整号码比对，不按尾号匹配。
只兼容明确的中国移动号码 +86/0086 写法，其他国际号码不猜测国家；短号、
字母地址及存在多个不同联系人候选的号码回退。无本地姓名时沿用原显示，
有姓名无照片时使用原文字头像。详情保留原始号码。

查询和缩略图解码在 IO 线程完成；使用有界内存缓存，不落盘复制通讯录。
联系人 ContentObserver 防抖失效，回到前台重新检查权限并刷新；关闭、撤权及离开
前台均丢弃显示缓存。姓名搜索在本地通讯录解析后匹配本地短信库，保留筛选、分页
和分组计数语义，不向网络发送姓名搜索词。不会为此更改通知采集的号码恢复规则。

## Web/PWA

仅在安全顶层上下文并支持 Contact Picker API 时允许用户选择联系人；检测 name/tel/icon
属性，不要求照片支持。API 不是持续通讯录访问授权，联系人改动需重新选择。
所选记录仅存当前源的 IndexedDB，与中枢元数据及短信缓存隔离；照片仅接受有大小
上限的 PNG/JPEG/WebP Blob，通过本地 object URL 显示，不获取外部头像 URL。
设置提供启用/停用和清除，清除后立即撤销 object URL；退出登录也清除所选联系人。
同源标签页收到更新后重新读取，失败显示明确提示而不声称已保存。
IndexedDB 同事务递增本地代次（清除仅保留无联系人数据的代次），旧标签页的在途保存不能复活已清除的联系人。

姓名搜索提供显式的“本机联系人”模式，完全在浏览器内筛选所选联系人，随后仅按
用户选择的短信发件号码打开会话；不把姓名或整份联系人号码列表发给中枢。
点击联系人后按页读取会话头并在本地完整号码匹配，保留不同原始发件地址的独立会话，
不会因只搜索已加载的第一页而遗漏旧会话；大量会话时该显式查询可能需要等待。
普通短信搜索维持原语义，两个输入/模式明确区分。不支持 API 的浏览器保留原显示。
浏览器可能回收本地存储；Android 与 PWA 不共享联系人数据。

中枢只增加静态模块白名单和图片 CSP 的 `blob:` 支持（不放宽脚本和网络来源）；
无新增联系人接口、数据库迁移、后台联系人读取或通知内容变更。

## 验证

自动测试覆盖号码规范化、不按尾号匹配、重复联系人歧义、无头像/坏头像、
缓存失效、禁用/撤权、搜索、上传模型隔离、Picker 能力降级、本地存储失败及清除。
真机验收另需验证系统授权、不同 ROM 的联系人变化通知、照片读取及浏览器 Picker UI；
编译和模拟测试不能替代这些实测。所有夹具使用虚构联系人。
