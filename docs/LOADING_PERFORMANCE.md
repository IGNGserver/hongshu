# 多端加载与弱网协议

## 目标与边界

加载分为应用壳、当前内容、增强信息、后台历史四层。壳和已缓存内容不等待网络；会话不等待分类统计、联系人全表或 AI 队列。Web、手机 PWA、桌面浏览器和桌面安装 PWA 共用实现，本仓库没有独立桌面程序。

不持久化浏览器短信，不缓存敏感 API，不自动切换中枢，不发布或部署。Android 继续使用原有持久队列、SQLite/WAL 和逐页事务游标。

## 公共静态壳

构建产物以内容 hash 命名 JS/CSS/图标，HTTP immutable；HTML 和 SW 必须校验更新。SW 只缓存同源明确白名单，优先使用当前版本已安装壳，必需资源安装完整才可切换。旧页面需要的旧壳缓存不随新版本激活删除。非必要图标不阻塞核心安装；应用提示更新，由用户重载后使用新壳。不使用全站 Cache Everything。

## 可选 API 能力

- `/me.features` 宣告 `metadata_revision`、`recent_snapshot`；旧客户端可忽略。
- `GET /api/metadata?since=N` 在一致性读事务中返回 `{revision,epoch,unchanged,devices?,sims?,contacts?}`。修订相同时不返回全表。修订由设备、SIM、联系人写事务同步更新；恢复以 epoch 隔离，不依赖修订永远递增。
- `GET /api/recent?limit=50` 返回 `{messages,head,epoch}`：最近会话的头消息展示快照；limit 为 1..200。head 是快照边界，**不是可提交的 sync cursor**。快照来自一个只读一致性事务，不产生已读/通知副作用。
- Android 的展示快照不推进 cursor、initial_head、initial_complete 或分析游标。预览标记持久保存，可靠同步遇到预览记录时仍按原规则处理通知，一次事务消耗标记，防止快照吞通知或重复通知。
- Web 保留旧 `/me` + 会话接口，关键内容最多两轮 API；元数据和统计独立补齐。AI 设置仅进入设置页时读取。

## 调度和退化

元数据按修订读取、同一会话合并并发；旧中枢使用有界 TTL。搜索取消旧请求，统计失败不使列表失败。认证失效与慢网/网关错误区别处理。慢网依据请求耗时滑动采样并提供手动模式；减少预取/后台并发，不盲目缩小高 RTT 同步页。

Android 有界同步轮次保证下载和上传公平，不让历史上传先占用二十批。联系人/分类为后置增强，最近展示独立于全历史补齐；身份锁仍保护整轮同步，缩小轮次而非放松身份隔离。本地会话摘要和索引只保存可重建派生状态，升级保留 outbox/采集证据。
每轮先提交一页下载再上传最多一批，并最多下载四页；上传有进展时追加后继补齐本机已 ACK 的消息。分类每轮两页、已读上报每轮二十个，未完成状态继续调度。手动/自动低速模式将上传字节预算降至 128KB，但保留 200 条同步页以避免高 RTT 下过多往返。单条超过预算的短信仍允许独立上传，不因低速模式永久阻塞。

## 测量与验收

仅记录固定请求类别、耗时、计数与加载阶段，不记录 URL 查询、正文、号码、Cookie、token 或验证码。Server-Timing 只提供处理耗时；客户端诊断保留有界内存样本。

隔离回归覆盖正常/延迟/超时/离线、统计挂起、元数据失败、身份切换、epoch 回档、快照与可靠页重叠、旧中枢兼容、壳升级和敏感缓存隔离。CI 使用合成数据，不能替代用户网络与真机验收。真实入口、机型和指标应记录在 VALIDATION.md，未测的性能目标不得写成已达到。

公开资源对照探测：`python3 scripts/probe-loading.py --origin https://your-hub.example --label cf --samples 3`。仅允许无凭据 origin，不输出响应内容/查询；每个资源首个样本含建连，后续尝试复用连接。该结果不是已登录整页速度。浏览器 CI 在挂起元数据/统计时断言列表可见，再验证离线重启壳；Android 原生 SQLite 测试验证预览不跳游标、不吞通知、摘要按时间/ID 排序和回档隔离。
