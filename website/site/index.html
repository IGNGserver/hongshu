PRIVATE RELAY

01 · 边界

能做什么，不能做什么。

收件与查看

短信上传到你自己的中枢，并在所有授权 Android 与 Web/PWA 设备上查看。首版只收件、查看，不发送短信。

自己的基础设施

Go + MySQL + Docker Compose。中枢镜像发布在 ghcr.io/igngserver/hongshu，部署与备份由你自己掌握。

隐私边界

不处理 MMS/RCS，不提供端到端加密；站点与示例不展示真实短信内容、手机号或其他个人数据。

02 · 开始

先读文档，再部署。

产品仍在预发布阶段。请只从 GitHub Releases 下载已发布的 Android 安装包，并按产品仓库的部署文档选择固定版本。
