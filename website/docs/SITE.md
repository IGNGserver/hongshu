# 官网定位与范围（SITE）

> 本文为后续开发者（含 AI 会话）提供站点上下文。范围或技术决策变化时同步更新本文件。

## 是什么

鸿枢 / Hongshu 的产品官网与下载入口：介绍产品、可视化跨设备消息归集与同步机制、提供交互式双端体验台、说明部署与隐私边界，并提供下载入口与文档链接。站点源码位于产品仓库的 `website/`：

| 事项 | 归属 |
| --- | --- |
| 产品功能、版本、发布资产、产品文档、Android/Web 客户端 | 产品仓库 `IGNGserver/hongshu`（`website/` 之外） |
| 官网页面、样式、3D 舞台与交互演示、SEO、站点文案 | `IGNGserver/hongshu/website/` |

注意：产品仓库内置的 `web/` 是产品自带的 Web/PWA 客户端；`website/` 是独立官网（产品站与下载入口），不要把产品客户端代码复制到这里。

## 当前状态（2026-11）

- 已完成官网视觉与交互重构，保持**零构建、零 npm 前端依赖、零第三方追踪与外链字体**；
- 视觉语言采用**暖白瓷面（Warm Alabaster）+ 雾蓝（Mist Blue）+ 柔和拉丝钛金金属边线**，对齐产品 Android/Web 的 Material 3 Expressive 语义令牌（`#0B57D0`、9 边形曲奇服务头像、OTP 时效卡片、双卡设备徽标），同时提供深色工作台主题切换；
- 首页内置零依赖原生 WebGL 3D 硬件与光路舞台（`site/assets/stage3d.js`），展示多台手机沿柔和光线路径汇入私有中枢并投射至桌面收件箱，配合滚动镜头编排与无 WebGL 环境自动降级；3D 屏幕/顶盖/卡片纹理采用与机身边框同心的圆角盒体（各向异性圆角半径）+ 片段着色器圆角 SDF 透明裁切 + `premultipliedAlpha: true` 合成，浅色模式下中枢顶面采用暖瓷浅钛材质，消除圆角黑边与深色斑块；
- 内置双端交互工作台（`site/assets/app.js` + `site/assets/data.js`），以 100% 虚构脱敏日常数据演示新验证码同步、设备与双卡筛选、搜索与一键复制验证码、只读通话记录切换、本机通讯录仅本地匹配对比，以及默认智能分类 / 可选 AI 精细分类切换与隐私提示；
- Cloudflare Pages 项目 `hongshu-website` 绑定正式域名 `hongshu.igng.net`，由 `.github/workflows/website.yml` 在 `main` 合并后自动静态检查并部署。

## 已定案

| 事项 | 决定 |
| --- | --- |
| 技术形态 | 零构建静态站点：HTML + CSS + 原生 ES Module（含 WebGL2/WebGL1 3D 舞台），发布目录 `website/site/` |

| 视觉方向 | 暖白 + 雾蓝 + 柔和金属质感消费级软件美学（支持暖白浅色默认态与深色工作台切换），避免赛博朋克霓虹风格 |

## 内容原则

- 只陈述产品仓库当前支持的事实，不编造路线图；版本与平台矩阵以产品仓库 `README.md` 与 `VERSION` 为准；
- 产品边界必须如实呈现：只读收件箱与只读通话记录、不通过运营商代发短信、不支持 MMS/RCS、不提供端到端加密（明文存于自建 MySQL）、本机联系人不上云、开启可选 AI 七分组时短信正文会发送给你选择的服务商；
- 文案面向普通多手机用户：首屏与主体功能介绍避免堆砌内部架构名词（如 `outbox`、`sync_clock`、权限或算法代号等），用生活化表达说明跨机查收、私密自主与可靠不漏信；Linux/Docker 部署命令与环境说明收敛在末尾「获取与安装」区块；
- 下载与部署文档链接锚定当前 `VERSION` 对应的 Release tag（`v<VERSION>`），不使用移动的 `main` 分支部署文档链接，也不在官网托管安装包；
- 演示数据必须 100% 虚构且号码脱敏（`check-site.py` 自动扫描拦截未脱敏 11 位手机号），不得展示任何真实短信内容、号码或个人数据；
- 品牌名遵循产品仓库规范：显示“鸿枢（Hongshu）”。
